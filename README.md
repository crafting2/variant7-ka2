# ЧАСТЬ А. ДКА

## Формальное описание

`M = (Q, Σ, δ, q₀, F)`:

- `Q = {(i,j) | i ∈ ℤ₅, j ∈ ℤ₃}`, `|Q| = 15`
- `Σ = {0, 1}`
- `δ((i,j), 0) = ((i+1) mod 5, j)`
- `δ((i,j), 1) = (i, (j+1) mod 3)`
- `q₀ = (0,0)`
- `F = {(0,0)}`

**Корректность (индукция по |w|):** после чтения `w` автомат находится в состоянии `(#₀(w) mod 5, #₁(w) mod 3)`. База: `w = ε` → `(0,0) ∈ F`. Шаг: `0` увеличивает первую компоненту, `1` — вторую. Значит, по завершении `w` состояние ∈ F ⟺ `#₀(w) ≡ 0 (mod 5)` и `#₁(w) ≡ 0 (mod 3)`. ∎

# ЧАСТЬ Б. НКА

## Формальное описание

`N = (Q, Σ, δ, q₀, F)`:

- `Q = {q0, q1, q2, q3}`
- `Σ = {a, b}`
- `q₀ = q0`
- `F = {q0, q1, q3}`

| δ | a | b |
|---|---|---|
| → q0 | {q1} | {q2} |
| *q1 | {q1} | ∅ |
| q2 | {q3} | {q2} |
| *q3 | ∅ | ∅ |

**Корректность:**  
- `aⁿ` (n ≥ 0): q0 → q1 (n раз). q0 и q1 финальные → Accept.  
- `bⁿa` (n ≥ 1): q0 → q2 (n раз) → q3. q3 финальное → Accept.  
- `bⁿ` без `a`: q2 не финальное → Reject.  
- `a…b…`: из q1 нет перехода по `b` → Reject.  
- `bⁿaᵏ, k ≥ 2`: из q3 нет переходов → Reject. ∎
